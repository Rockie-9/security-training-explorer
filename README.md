# 企業安全防護訓練檢索 | Security Training Explorer

> GSM / GPS · 25 certifications · Fact-checked 2026-03-25 · Industry benchmarks included

互動式企業安全訓練認證檢索工具，涵蓋四大角色軌道（接待、保全、中控、戰略指揮），具備全文搜尋、多軸篩選、學習路徑、預算總覽及業界採用基準。

## Features

- 🔍 **Full-text search** across all certification fields
- 🏷️ **4-axis filtering**: Priority / Role / Level / Cost
- 📊 **Budget Dashboard**: Per-track cost estimates
- 🛤️ **Learning Paths**: Sequenced progression per role
- 🏢 **Industry Benchmarks**: Adopting companies & sectors
- 🌐 **Bilingual**: zh-TW / EN toggle
- 🌙 **Dark / Light** theme
- ✅ **Fact-checked**: 20 verified, 5 partial, 0 unverifiable
- 🔗 **Official URLs** for each certification body

## Deploy

### Vercel (Recommended)
1. Push to GitHub
2. Import in [vercel.com/new](https://vercel.com/new)
3. Framework: **Vite** (auto-detected)
4. Deploy ✅

### Local Development
```bash
npm install
npm run dev
```

## Tech Stack
- Vite + React
- lucide-react (icons)
- Inline CSS with CSS Custom Properties (no Tailwind dependency)
